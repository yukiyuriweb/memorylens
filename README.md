# MemoryLens

A lightweight, native macOS menu bar monitor for memory — how much is left, how much pressure the system is under, and which apps are using it.

Memory cleaner apps make the “free” number go up by flushing caches or pushing other apps' memory into swap, which usually makes things slower. MemoryLens does not do that. It shows what Activity Monitor shows, in one glance from the menu bar, and lets you quit the app that is actually using the memory.

- Remaining memory (physical memory minus used) in the menu bar
- Memory pressure: normal, warning or critical
- The same breakdown as Activity Monitor: App Memory, Wired, Compressed, Cached Files, Free and Swap
- The 10 apps using the most memory, with helper processes counted towards their app (all of a browser's renderers count as the browser)
- Hover over an app to quit it; apps with unsaved documents still ask first
- Written in Swift and SwiftUI with Liquid Glass — no Electron, no dependencies

The interface is in English and Japanese, following the system language. Processes running as root are not counted in the app list, because their memory cannot be read without privileges.

## Requirements

- macOS 26 or later
- Xcode or the Xcode Command Line Tools (Swift 6)

## Build

```sh
./build.sh
```

This produces `build/MemoryLens.app`. `./build.sh --install` also copies it to `~/Applications` and relaunches it.

To start MemoryLens at login, add it under System Settings → General → Login Items.

## App icon

`Resources/AppIcon.icns` is generated by `make-icon.swift`:

```sh
swift make-icon.swift
```
